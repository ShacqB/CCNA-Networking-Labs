# CCNA Lab 02 — Ethernet Cabling

## Overview
Practiced connecting network devices in Cisco Packet Tracer using the correct Ethernet and fiber-optic cables.

## Tools
- Cisco Packet Tracer

## What I Did
- Connected PCs, switches, and routers using straight-through and crossover cables.
- Used single-mode fiber for a 3 km connection.
- Used multimode fiber for a 250 m connection.
- Built a network topology with 4 routers, 8 switches, 3 PCs, and 1 server.

## What I Learned
- Straight-through cables are typically used between different device types.
- Crossover cables are used between similar devices when Auto-MDI-X is disabled.
- Single-mode fiber is better suited for longer distances.
- Multimode fiber is commonly used for shorter distances.
- Auto-MDI-X allows devices to automatically adjust for different Ethernet cable types.

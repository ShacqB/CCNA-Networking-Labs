
# CCNA Networking Labs

A collection of hands-on networking labs completed using Cisco Packet Tracer while studying networking fundamentals and preparing for the CCNA certification. These labs document my configurations, verification steps, troubleshooting, and what I learned along the way.

## Tools
- Cisco Packet Tracer
- Cisco IOS

## Topics Covered
- Network topologies
- Ethernet and fiber-optic cabling
- IP addressing and subnetting
- Ethernet LAN switching
- MAC address learning and forwarding
- ARP and ICMP
- VLANs and switching
- Static IPv4 routing and next-hop addresses
- Basic network device security
- Cisco IOS configuration
- Network troubleshooting

## Completed Labs

| Lab | Description |
|---|---|
| [Day 02 - Ethernet Cabling](Day-02-Ethernet-Cabling/) | Connected network devices using appropriate cable types, including copper Ethernet and fiber-optic cabling. |
| [Day 04 - Basic Device Security](Day-04-Basic-Device-Security/) | Configured device hostnames, enable passwords, password encryption, and enable secrets on Cisco routers and switches. |
| [Day 06 - Ethernet LAN Switching](Day-06-Ethernet-LAN-Switching/) | Explored MAC address learning, Ethernet frame forwarding, ARP requests, and dynamic MAC address tables across multiple switches. |
| [Day 11 - Static Routing](Day-11-Static-Routing/) | Configured static routes across three routers to connect two LANs; practiced identifying next-hop IP addresses, verifying routing tables, and troubleshooting connectivity. |

## Goal

Develop practical networking skills through hands-on labs, Cisco IOS device configuration, routing, switching, security, and troubleshooting. I use this repository to track my CCNA learning progress and demonstrate my ability to apply networking concepts in simulated environments.

*These are study labs based on Jeremy's IT Lab CCNA course. Each lab documents my own implementation and learning process.*

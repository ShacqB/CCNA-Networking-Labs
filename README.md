# CCNA Networking Labs

A collection of hands-on networking labs completed using Cisco Packet Tracer while studying networking fundamentals and preparing for the CCNA certification.

## Tools
- Cisco Packet Tracer
- Cisco IOS

## Topics Covered
- Network topologies
- Ethernet and fiber-optic cabling
- IP addressing and subnetting
- Ethernet LAN switching
- MAC address learning and forwarding
- ARP and ICMP
- VLANs and switching
- Routing protocols
- Basic network device security
- Cisco IOS configuration
- Network troubleshooting

## Completed Labs

| Lab | Description |
|---|---|
| [Day 02 - Ethernet Cabling](Day-02-Ethernet-Cabling/) | Connecting network devices using appropriate cable types, including copper Ethernet and fiber-optic cabling |
| [Day 04 - Basic Device Security](Day-04-Basic-Device-Security/) | Configuring device hostnames, enable passwords, password encryption, and enable secrets on Cisco routers and switches |
| [Day 06 - Ethernet LAN Switching](Day-06-Ethernet-LAN-Switching/) | Exploring MAC address learning, Ethernet frame forwarding, ARP requests, and dynamic MAC address tables across multiple switches |

## Goal

Develop practical networking skills through hands-on labs, device configuration, security, switching, and troubleshooting while building a portfolio of practical CCNA-related experience.
